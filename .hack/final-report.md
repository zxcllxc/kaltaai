## Флаги (`src/lib/flags.ts`)
| Флаг | Состояние | Почему |
|---|---|---|
| `telegram` | ✅ вкл | Бот проверен: вебхук без ошибок, секрет проверяется, команды RU/KZ |
| `quickStart` | ✅ вкл | 5 вопросов → дашборд, проверено на проде |
| `photo` | ✅ вкл | Фото тетради → 6 строк за ~13 с → подтверждение → дашборд; одна авто-повторная попытка |
| `aiCache` | ✅ вкл | Демо-тексты ИИ в бандле: на питче всё мгновенно и без сети |
| `voice` | ⛔ выкл | В NVIDIA NIM распознавание речи только по gRPC; REST-ключом недоступно. Нужен бесплатный ключ Groq |

Выключить любой флаг: переменная окружения в Vercel `NEXT_PUBLIC_FLAG_<ИМЯ>=0` + передеплой. Проверить выключенный флаг только у себя: `/?ff=voice`.

### Этап 2 — надёжность
- SSR лендинга и /pitch; без JS виден лендинг; `/?demo=shop` открывает демо.

- Таймауты (сервер 10 с, клиент 12 с), error boundary на каждый экран, localStorage в try/catch (проверено с заблокированным хранилищем), лимит ИИ по IP, вопрос ≤ 300 символов.
- Slow 3G: кнопка демо через 2,5–2,9 с. Lighthouse mobile: лендинг 94–96 / доступность 100, /pitch 99 / 96.
