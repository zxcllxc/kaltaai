# План
Цель: владелец за 1 клик видит, когда кончатся деньги, где заморожены ₸ и 3 действия с эффектом в ₸.

## Сценарий демо (2 мин)
Лендинг → «Демо-данные» → дашборд: красная плашка «28 окт разрыв −340 000 ₸» → график 14 дней → утечки → 3 действия (+₸) → вкладка «Брифинг» в стиле Telegram → «Предотвращённый разрыв / Замороженные деньги».

## Архитектура
- Всё считается в браузере (lib/analytics.ts — чистые функции): без БД, мгновенно, приватно.
- Формат данных: одна таблица CSV/XLSX `date,type,item,qty,amount` (type: sale|purchase|rent|salary|other) + шаблон для скачивания.
- Парсинг: papaparse (CSV) + xlsx/SheetJS (Excel).
- Демо-генератор: детерминированный (seed), «Магазин продуктов, мкр. Аса, Тараз», остаток кассы задан.
- LLM: API route /api/advice → NVIDIA NIM (OpenAI-совместимый, `meta/llama-3.3-70b-instruct`), получает JSON с цифрами, возвращает формулировки. Фолбэк: шаблонные тексты, если ключа нет/ошибка (демо не ломается). Проверка: LLM не может менять числа — суммы подставляет код.
- График: recharts (shadcn chart).

## Шаги
1. Scaffold Next.js + Tailwind + shadcn, git init. Готово, когда: `npm run dev` открывается.
2. Демо-генератор + analytics (прогноз, разрыв, утечки, действия). Готово, когда: на демо-данных есть разрыв в 14 днях и 3–5 мёртвых товаров.
3. Дашборд: загрузка/демо, KPI, график, утечки, действия. Готово, когда: клик → всё видно, мобилка ок.
4. NIM route + фолбэк. Готово, когда: тексты от LLM приходят, без ключа — шаблон.
5. Telegram-чат брифинг. Готово, когда: сообщения пузырями с ₸.
6. Загрузка CSV/XLSX + шаблон. Готово, когда: скачанный шаблон загружается обратно и даёт те же цифры.
7. Деплой Vercel + env, README, pitch. Готово, когда: прод-ссылка проходит сценарий.
