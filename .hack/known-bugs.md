# Известные ограничения (на 18.10.2026)

- **Производительность дашборда демо** в Lighthouse mobile — ~71–74 (TBT ~500 мс на эмулированном слабом CPU: React + графики). Лендинг 94–96, /pitch 99, доступность везде 96–100.
- **Голосовой ввод выключен** (флаг `voice`): в NVIDIA NIM распознавание речи доступно только по gRPC, через REST-ключ его нет. Нужен бесплатный ключ Groq (whisper-large-v3) — см. final-report.
- **Бот** работает на демо-данных; свои данные — на сайте.
- **Ответ ИИ в чате** обычно 1,5–5 с, изредка дольше 6 с; через 12 с без ответа показывается шаблон, посчитанный кодом. Формулировки ИИ на казахском иногда неуклюжие, но числа и смысл проверяются (в ответе допустимы только числа из расчёта кода).
- **Выбор типа бизнеса до загрузки JS** (очень медленный интернет) не запоминается: кнопка «Попробовать на демо» откроет магазин. Переключатель языка и ссылка демо до загрузки JS работают.
- **Остаток в кассе для своего файла** — оценка, нужно уточнить вручную (поле на главной).
- **Прогноз** — средние по дням недели за 4 недели, без сезонности и праздников.
- **Локально** (`next start` / `next dev`) запросы к NIM иногда зависают до таймаута 10 с; на Vercel ответы за 2–5 с. Демо-тексты ИИ поэтому генерируются скриптом против прода.
- Модели Llama 3.x на NIM сняты (410) — используется `openai/gpt-oss-20b` (меняется через `NVIDIA_MODEL`).
- `react-hooks/set-state-in-effect` в lint на эффектах загрузки — на работу не влияет.
